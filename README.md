# Sistema de Alquiler de Vehículos

## Descripción
Sistema de software diseñado para facilitar la administración de una empresa de alquiler de vehículos, organizando las operaciones y la información de clientes, vehículos y alquileres.

## Objetivo
Desarrollar un sistema que permita gestionar el proceso de alquiler de vehículos, desde el registro de clientes y la consulta de disponibilidad hasta las reservas, devoluciones y pagos.

## Funcionalidades principales
- Gestión de vehículos.
- Gestión de clientes.
- Categorías y tarifas.
- Consulta de disponibilidad.
- Gestión de reservas.
- Registro de alquileres y devoluciones.
- Registro de pagos.

## Tecnologías
Por definir.

## Equipo de desarrollo
Proyecto académico grupal de la asignatura de Ingeniería de Software II.

## Estado del proyecto
En etapa de planificación y organización inicial.
